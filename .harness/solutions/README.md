# Harness Solutions

`.harness/solutions/**` stores verified, reusable Harness Engineering solution
captures. It replaces ad hoc `docs/solutions/**` writes for new HE work while
preserving legacy solution docs as source evidence.

Add or refresh an entry only when the fix or decision is useful beyond one
session and includes:

- a governed asset or asset family;
- concrete source evidence;
- concise problem and resolution sections;
- maintenance ownership;
- a freshness marker;
- Project Brain status when `.harness/knowledge/**` is in use.

Keep raw investigation logs, temporary task notes, and unresolved incidents out
of this folder.
