# Future Agent Operating Rules

Purpose: durable behavioral contract for future agents.

## Start Here

- Use `./bin/ask` before ad hoc repo spelunking.
- Treat `repo doctor` as first truth.
- Follow the golden path unless the task explicitly requires deeper work.
- Prefer exact command evidence over inferred state.

## Preserve

- deterministic execution;
- source/projection separation;
- generated handle shallowness;
- `--json --robot` contracts;
- runtime budget;
- proof semantics;
- path ownership;
- closeout evidence.

## Challenge

- new skill breadth without outcome scenario;
- new command paths outside the golden path;
- new governance without proof target;
- docs that duplicate command output;
- compatibility without expiry;
- generated files treated as source;
- artifact retention without index or fixture value.

## Rewrite Freely When Safe

- tactical internals;
- overgrown command modules;
- stale docs;
- weak or overlapping skill text;
- unowned compatibility wrappers;
- artifact layout;
- CI internals with preserved check semantics.

## Require Human Review

- public `ask` command contract changes;
- source/projection model changes;
- command-handle semantics;
- selection policy or runtime budget changes;
- proof taxonomy changes;
- required-check pruning;
- deletion of uncertain historical evidence.

## Closure Rule

Do not claim completion until the relevant validation, eval, or closeout evidence exists.
