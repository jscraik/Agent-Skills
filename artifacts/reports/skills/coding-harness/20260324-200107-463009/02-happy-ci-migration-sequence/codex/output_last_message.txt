**Rollback**

- Before `harness ci-migrate commit`, use the harness rollback:
```bash
harness ci-migrate abort --snapshot <snapshot-id>
```

- After `harness ci-migrate commit`, the safe rollback is a normal git rollback, not another manual file surgery:
```bash
git revert <migration-commit-sha>
```
Because that becomes a high-risk git operation on CI/governance files, I’d pause and confirm branch state before doing it.
