## Scope and triggers
- Applies to `skill-builder` reviews in `eval`/`improve` mode where we need explicit quality gates and release criteria.
- Goal for this review: surface the gold validation commands and enforce security as a hard release gate.

## Required inputs
- Skill path to validate: `<path/to/skill-folder>`.
- No additional inputs needed to define the gate policy.

## Deliverables
- Gold validation command set (core gates + required evals).
- Release-blocking rule: any security finding blocks release (not only PI-high).
- Machine-checkable contract showing `warnings_block_release: true`.

## Failure mode
- If any security finding/warning appears in gate outputs, release status is `blocked`.
- If a gold gate fails, stop and fix before continuing to later gates.

**Gold Validation Commands**
```bash
python3 utilities/skill-builder/scripts/quick_validate.py <path/to/skill-folder>
python3 utilities/skill-builder/scripts/skill_gate.py <path/to/skill-folder> --require-fail-fast --require-security-evals --pi-high-fail
python3 utilities/skill-builder/scripts/analyze_skill.py <path/to/skill-folder>
python3 utilities/skill-builder/scripts/openclaw_skill_guard.py <path/to/skill-folder> --mode both
python3 utilities/skill-builder/scripts/run_skill_evals.py <path/to/skill-folder>
```

**Reliability Checks (required for `eval`, `benchmark-lite`, install writes)**
```bash
python3 utilities/skill-builder/scripts/run_skill_evals.py <path/to/skill-folder> --dual-run --capture-jsonl
python3 utilities/skill-builder/scripts/deterministic_trace_checks.py <path/to/codex-run.jsonl> --budgets-json '{"max_total_tokens":4000,"max_duplicate_command_ratio":0.35}'
```

**Release-blocking security policy**
- Treat all security findings as blocking: PI-high and non-PI warnings.
- Operational rule: if any validator reports security warnings/findings, promote to `fail` for release decision.
- Keep output contract set to:
```json
{
  "security": {
    "pi_high_blocking": true,
    "warnings_block_release": true
  }
}
```
