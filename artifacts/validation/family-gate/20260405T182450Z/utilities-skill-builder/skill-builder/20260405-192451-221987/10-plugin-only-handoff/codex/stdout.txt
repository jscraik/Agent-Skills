## Deliverables
I can’t create or modify files in this session because this sandbox is read-only for writes, so here is the exact minimal command sequence to run in your writable shell:

```bash
set -euo pipefail

cd /Users/jamiecraik/dev/agent-skills

# 1) Scaffold plugin shell
mkdir -p plugins/skill-builder/.codex-plugin plugins/skill-builder/skills
rm -rf plugins/skill-builder/skills/skill-builder
rsync -a --delete --exclude='.DS_Store' utilities/skill-builder/ plugins/skill-builder/skills/skill-builder/

# 2) Add plugin runtime manifest (minimal valid runtime surface + optional metadata)
cat > plugins/skill-builder/.codex-plugin/plugin.json <<'JSON'
{
  "schema_version": 1,
  "name": "skill-builder",
  "version": "0.1.0",
  "description": "Skill quality and lifecycle tooling for Codex skills.",
  "author": {
    "name": "Jamie Craik"
  },
  "homepage": "https://github.com/jscraik/Agent-Skills",
  "repository": "https://github.com/jscraik/Agent-Skills",
  "license": "MIT",
  "skills": "./skills/",
  "interface": {
    "displayName": "Skill Builder",
    "shortDescription": "Validate, improve, compare, and package Codex skills.",
    "longDescription": "A packaged distribution of the already-validated standalone skill-builder utility.",
    "developerName": "Jamie Craik",
    "category": "Productivity",
    "capabilities": [
      "Interactive",
      "Read",
      "Write"
    ],
    "websiteURL": "https://github.com/jscraik/Agent-Skills",
    "defaultPrompt": "Use the skill-builder workflow for safe, evidence-led skill lifecycle packaging.",
    "brandColor": "#0D99FF"
  }
}
JSON

# 3) Register plugin in both local marketplace catalogs (idempotent upsert)
python3 - <<'PY'
import json
from pathlib import Path

files = [Path("plugins/marketplace.json"), Path(".agents/plugins/marketplace.json")]
entry_name = "skill-builder"
entry = {
  "name": entry_name,
  "source": {"source": "local", "path": f"./plugins/{entry_name}"},
  "policy": {"installation": "AVAILABLE", "authentication": "ON_INSTALL"},
  "category": "Productivity"
}

for path in files:
    data = json.loads(path.read_text())
    plugins = data.get("plugins", [])
    if not any(p.get("name") == entry_name for p in plugins):
        plugins.append(entry)
        data["plugins"] = sorted(plugins, key=lambda p: p["name"])
        path.write_text(json.dumps(data, indent=2) + "\n")
PY

# 4) Optional sanity check
python3 -m json.tool plugins/skill-builder/.codex-plugin/plugin.json > /dev/null
jq . plugins/marketplace.json >/dev/null && jq . .agents/plugins/marketplace.json >/dev/null
```

## Failure mode
- If writes are blocked (as in this session), the blocker is environmental, not a packaging logic issue.
- If plugin validation fails after this point, it will usually be one of:
  - missing/invalid manifest path fields,
  - duplicate plugin name without overwrite handling,
  - marketplace policy/schema mismatch if non-canonical fields remain in catalogs.

- No skill reauthoring performed: `utilities/skill-builder` remains untouched.
