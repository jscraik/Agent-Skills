# Discovery Interview

Use this reference when an agent-native readiness request is underspecified.

## Request user input mini-templates

Round 1 question: What should this skill help you do?

Why this matters: the target path, artifact shape, and edit authority decide which repo evidence to inspect and which validation claims are allowed.

Ask one round at a time. Use a plain-language question. Do not draft the audit, score, or patch plan until the target and authority are clear.
