# Architecture Practice Contract

## Architecture Decision Loop

Before choosing a design, gather: source-of-truth, public surface, caller map,
change class, boundary verdict, first move, and verifier.

## Reference Use

- classification-cheatsheet.md: safe/risky/blocked verdicts.
- output-schema.md: risky, blocked, handoff, or eval-proof responses.
- contract.yaml: package, version, Tessl, Plugin Eval, and evidence policy.
- deepening-workflow.md: replace generic refactor prose with proof.

## Trap Rules

Pattern names, passing tests, generated files, runtime mirrors, caches,
dashboards, tracker comments, logs, Tessl, KnowledgeOS, and capsules are
evidence only unless repo-controlled source makes them authority.
