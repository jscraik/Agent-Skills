## Selection And Evidence

1. Start from the approved change and select at most three relevant lenses.
2. Convert a lens into checks or questions, not an assumed conclusion.
3. Keep the skill entrypoint small; load supporting detail only when needed.
4. Use concrete repository evidence and the target repository's validation.
5. Use evals to establish whether the selected lens changes the desired behaviour.
