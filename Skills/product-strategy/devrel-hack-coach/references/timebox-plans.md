# Timebox Plans

## 24-Hour Build

Ask the user to name exactly what will exist at each checkpoint because vague
milestones hide scope risk.

| Checkpoint | Hour | What must exist |
| --- | --- | --- |
| Smoke test | T+2h | End-to-end skeleton. Ugly. Works. |
| Golden path | T+8h | Demo moment works on stage-quality input. |
| Second scenario | T+16h | Failure case or variation showing judgment. |
| Pitch dry-run | T+22h | Demo script written and timed once. |

Exit gate: one concrete named artifact at each checkpoint. If the user cannot
name it, go back to Phase 2 and cut scope. The plan must also name the one live
golden path and what is mocked, stubbed, or deferred.

## 1-Hour Prep Sprint Or 5-Minute Project Presentation

Compress the plan to these checkpoints:

- first 10 minutes: lock the wedge
- next 20 minutes: rehearse the demo path
- next 20 minutes: write the three-sentence pitch and Q&A
- final 10 minutes: time the handoff

The demo itself should still be no longer than 60 seconds unless the user
explicitly has a longer judging slot.
