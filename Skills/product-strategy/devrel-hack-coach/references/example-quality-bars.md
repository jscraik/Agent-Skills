# Example Quality Bars

Use these examples only as quality bars. Do not copy them blindly.

- `references/examples/good-spec.md`: spec concreteness, stage-visible demo
  moment, pressure test, fallback path, and red flags.
- `references/examples/good-pitch.md`: three-sentence pitch, judge reveal
  order, Q&A, and real-vs-mocked boundary.

Open one example only when the current phase needs that quality bar.
