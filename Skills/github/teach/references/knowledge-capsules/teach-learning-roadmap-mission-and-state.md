## Load When

## Guidance

- Confirm the learning mission before creating lessons.
- Record non-obvious learning, mission changes, blockers, and future-session steering.
- Pick one next lesson, not a broad syllabus, unless the user explicitly asks for roadmap planning.
- Keep source trust and certification boundaries visible in the mission.
- When multiple goals share a practice substrate, sequence them so one artifact reinforces several targets.
