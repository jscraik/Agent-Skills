## Load When

Use this capsule when the user asks for a roadmap, multi-session plan, or a course sequence across related targets.

## Guidance

- Start from the mission and official source boundaries, then map practice tracks.
- Prefer a shared practice substrate when targets overlap, such as one project that teaches TypeScript types, Python automation, or eval design across several lessons.
- Sequence by dependencies and durable wins: mental model, small artifact, retrieval practice, then record.
- Use local books to enrich depth after official scope is established.
- Keep roadmap plans adjustable from learning records rather than frozen upfront.
