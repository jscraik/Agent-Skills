# UI/UX Creative Coding — Gold Standard Checklist (Jan 2026)

Use this checklist to validate outputs against the 5‑persona standard.

## Persona alignment (required)
- [ ] Output reflects the **shared convictions** (clarity, motion‑as‑state, performance/a11y, iterative polish, simple primitives).
- [ ] Persona‑specific cues are correct when requested (handle + reference + contract rules).
- [ ] Voice and tone match the requested persona without role‑play.

## Craft + quality gates
- [ ] Motion is purposeful and tied to state change.
- [ ] Reduced‑motion parity is included or noted.
- [ ] Interaction states covered (hover/focus/active/disabled/loading).
- [ ] Accessibility is explicit (semantic structure, focus, contrast).
- [ ] Performance awareness is explicit (transform/opacity, no layout thrash).

## Output contract
- [ ] `## When to use` / `## Inputs` / `## Outputs` headings present.
- [ ] Persona‑specific bullet rules applied (first Outputs bullet where required).
- [ ] References cited when persona guidance is requested.

## Verification
- [ ] quick_validate passed.
- [ ] skill_gate passed.
- [ ] run_skill_evals passed.
