# Critical Pattern Template

Use this template when adding a pattern to a `docs/solutions/patterns/critical-patterns.md` style document:

---

## N. [Pattern Name] (ALWAYS REQUIRED)

### ❌ WRONG ([Will cause X error])
```[language]
[code showing wrong approach]
```

### ✅ CORRECT
```[language]
[code showing correct approach]
```

**Why:** [Technical explanation of why this is required]

**Placement/Context:** [When this applies]

**Documented in:** `docs/solutions/[category]/[filename].md`

---

Instructions:
1. Replace `N` with the next pattern number.
2. Replace `[Pattern Name]` with a descriptive title.
3. Fill in the wrong example with code that causes the problem.
4. Fill in the correct example with the solution.
5. Explain the technical reason in `Why`.
6. Clarify when the pattern applies in `Placement/Context`.
7. Link back to the full troubleshooting document.
