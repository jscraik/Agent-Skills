# Skill Quality Heartbeat - 2026-04-25

Purpose: drive repeated skill-quality improvement batches until skills are strict-audit clean, plugin-eval reviewed, security-checked, projection-valid, and committed at regular checkpoints.

## Cadence

- Heartbeat update: after each evaluation batch, fix batch, validation batch, and commit checkpoint.
- Commit checkpoint: after every coherent green batch or before switching skill families.
- Stop condition: no actionable A-grade blockers remain in the current batch, or a blocker requires user/project decision.

## A-Grade Gate

Each skill batch must pass:

- `./bin/ask skills audit <skill-path> --level strict --robot`
- `plugin-eval analyze <skill-path> --format json` or equivalent local Plugin Eval command
- security review for secrets, unsafe shell/network behavior, untrusted input, and dangerous file mutation
- `bash Infrastructure/scripts/validation-and-linting/lint_openai_skill_format.sh --mode strict`
- `bash Infrastructure/scripts/validation-and-linting/lint_progressive_disclosure.sh --mode warn`
- `bash Infrastructure/scripts/validation-and-linting/lint_skill_types.sh`
- `python3 Infrastructure/scripts/validation-and-linting/check_context_budget.py --projection rooted`
- `bash Infrastructure/scripts/lifecycle-and-sync/validate_projection_integrity.sh`
