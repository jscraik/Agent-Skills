## Goal

Compress and clarify the repo’s agent-facing instruction surfaces so agents can find the right canonical source quickly, avoid duplicated policy, and make safer changes to skills, runtime projections, and workflow docs.

This parent tracks the first small milestone of the broader refactor program: instruction surface compression and ownership cleanup.

## Context

The current repo has several overlapping truth surfaces, including root `AGENTS.md`, `Docs/agents/*`, runtime projections, skill docs, command contracts, and workflow summaries. The refactor should preserve behavior while moving detailed rules into canonical owners and turning higher-level surfaces into concise maps.

Known canonical anchors:

- `UBIQUITOUS_LANGUAGE.md`
- `Docs/agents/README.md`
- `Docs/agents/02-tooling-policy.md`
- `Docs/agents/04-validation.md`
- `Docs/agents/13-workflow-and-safety-guidance.md`
- `Docs/agents/14-path-ownership-boundaries.md`
- `Docs/agents/16-agent-operating-contract.md`
- `Docs/agents/17-skill-management.md`
- `Docs/agents/18-browser-and-local-preview.md`
- `Docs/agents/05-contradictions-and-cleanup.md`

## Scope

- Compress duplicated repo guidance.
- Preserve current command and validation behavior.
- Clarify canonical ownership boundaries.
- Make runtime projection guidance harder to violate.
- Keep changes small enough to validate with repo wrappers.

## Out of Scope

- Redesigning the entire docs system.
- Changing command semantics without a dedicated issue.
- Moving runtime projection generation logic unless required by validation.
- Creating new broad process surfaces.

## Acceptance Criteria

- Root `AGENTS.md` is short and points to canonical docs rather than restating them.
- Duplicated guidance has either been removed or explicitly marked as canonical in one place.
- Path ownership rules are clear before editing skills, projections, or agent-facing docs.
- Validation evidence is captured with `./bin/ask repo closeout --changed --json --robot`.
- No behavior-changing refactor lands without focused proof.

## Validation

Run, at minimum:

./bin/ask repo closeout --changed --json --robot
```
