**Equivalence Standard**

   It must preserve the original execution posture: agent as strategic operator, not passive summarizer; evidence-first; repo-aware; willing to challenge weak premises; biased toward implementation progress.

   It must accept the same real-world inputs the long prompt handled: messy context, partial repo state, prior attempts, constraints, product/engineering ambiguity, and user taste.

   It must preserve HE-specific ideas rather than flattening them into generic “software planning”:

   The long-form method likely carried a lot of tacit judgment: when to ask, when to proceed, when to spawn reviewers, when to stop broadening scope. The strategy artifact is only equivalent if it encodes those decision points explicitly enough that another agent can reproduce the behavior.

   If the artifact compresses the original prompt, compression is fine. But it is not equivalent if it removes:

   adversarial review posture,
   repo-specific evidence expectations,
   artifact naming or closeout conventions,
