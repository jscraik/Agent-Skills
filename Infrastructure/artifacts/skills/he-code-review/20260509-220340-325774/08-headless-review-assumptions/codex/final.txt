Yes. For unattended reviews, I’ll avoid stopping on non-blocking clarification questions.

I’ll handle it like this:

- Record assumptions explicitly, including what I inferred and why.
- Add confidence for each important assumption or finding, for example `high`, `medium`, or `low`.
- Only ask the user if something is genuinely blocking or could cause destructive/irreversible work.
- For review output, keep questions in an `Assumptions / Open Questions` section instead of interrupting the flow.
- If confidence is low but the work can still proceed, I’ll state the risk and continue with the best-supported interpretation.

So the review shape will be more like:

```text
Finding: ...
Severity: ...
Confidence: Medium
Evidence: ...
Assumption: I’m assuming X because Y.
Recommended fix: ...
```

That should make unattended review runs much smoother: fewer pauses, more usable output, and clearer places for you to verify later.
