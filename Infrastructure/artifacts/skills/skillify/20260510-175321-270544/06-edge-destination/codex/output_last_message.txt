# AGENTS.md Instruction Scope

Use this skill when you need to determine which `AGENTS.md` instructions apply before reading, editing, validating, or reporting on files in a workspace.

## Workflow

1. Locate applicable `AGENTS.md` files.
   - Check the filesystem path from the workspace root to the target file or directory.
   - Remember that `AGENTS.md` files can appear anywhere, including `/`, the home directory, repository roots, and nested subdirectories.
   - Do not assume they only appear in version-controlled directories.

2. Determine scope.
   - Each `AGENTS.md` governs the directory containing it and every child path beneath that directory.
   - For each file you plan to change, apply every `AGENTS.md` whose scope includes that file.

3. Resolve precedence.
   - System, developer, and direct user instructions outrank `AGENTS.md`.
   - When multiple `AGENTS.md` files apply, the deeper file overrides conflicting guidance from higher-level files.
   - Non-conflicting guidance from higher-level files still applies.

4. Validate before editing.
   - Before changing a file, identify the exact applicable instruction stack for that path.
   - If the applicable category, ownership boundary, or destination is unclear, stop and ask for clarification.
   - Do not infer a destination when the instructions require validation.

5. Report evidence.
   - When useful, cite the relevant `AGENTS.md` paths and the target file path.
   - For blocked work, state which category or destination could not be validated.
