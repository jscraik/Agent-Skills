The checkpoint / proof-gate / stop-condition interpretation is:

- Checkpoint 1: spec approved, open questions resolved.
- Checkpoint 2: plan approved, tasks are small and testable.
- Checkpoint 3: each implementation slice has evidence, usually tests or runtime verification.
- Checkpoint 4: review passes before merge or ship.
- Stop conditions: unresolved ambiguity, missing verification evidence, failed tests, or review objections block advancement until corrected.
