# Architecture Review Document

## Title
`<Project / Feature Name> Architecture Review`

## Purpose
This document evaluates the proposed architecture for `<feature/system>` and records the recommended approach, the reasoning behind it, the tradeoffs, and the implementation considerations needed to ship safely.

This is intended to replace a Linear execution plan when the goal is architectural alignment rather than task tracking.

## Executive Summary
The proposed architecture should:

- Solve `<primary problem>`
- Minimize `<key risk or constraint>`
- Fit within the current system boundaries of `<existing system>`
- Preserve or improve `<performance / reliability / maintainability / UX / security>`

**Recommendation:** `<recommended approach>`

**Confidence:** `<high | medium | low>`

**Why this approach:** `<1-3 sentence summary of the main reasons>`
