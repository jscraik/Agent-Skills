Yes. A clean way to classify proposed work is:

- `Now`: work that is required immediately to achieve the current goal, unblock others, or address a live risk. It should be actionable now and fit the current scope.
- `Next`: work that is clearly valuable and likely should happen soon, but is sequenced after the current batch or depends on something in `Now`.
- `Later`: work that could be useful eventually, but is not time-sensitive and should stay in the backlog until there is a stronger reason to do it.
- `Do Not Create`: work that should not be added at all because it is out of scope, speculative, premature, duplicative, or inconsistent with the intended direction.

A simple decision test:

- Put it in `Now` if delaying it would block the main outcome.
- Put it in `Next` if it matters but can wait for the current round to finish.
- Put it in `Later` if it is a nice-to-have, enhancement, or future possibility.
- Put it in `Do Not Create` if it adds noise, unnecessary complexity, or a new item that we already know we should not pursue.
