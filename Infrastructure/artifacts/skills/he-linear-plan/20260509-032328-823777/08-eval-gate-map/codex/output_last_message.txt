**Gate legend**
- **Build**: package/release hygiene, artifact validity, repo publishability
- **Test**: validation, fail-fast checks, example correctness, runtime safety
- **Drift**: docs vs reality, stale duplication, provenance mismatch
- **Routing**: discovery, naming, skill selection, task-to-skill matching
- **Rollback**: update/revert path, provenance, lifecycle safety after publish
