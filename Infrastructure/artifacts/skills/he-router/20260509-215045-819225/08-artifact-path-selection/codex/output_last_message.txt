For a Linear-linked plan update created today, use the dated canonical harness artifact path pattern:

```text
Docs/harness/artifacts/2026-05-09-linear-<LINEAR_KEY>-plan-update.md
```

Replace `<LINEAR_KEY>` with the actual Linear issue key, for example:

```text
Docs/harness/artifacts/2026-05-09-linear-ASK-123-plan-update.md
```

I’d use **May 9, 2026** because your environment date is `2026-05-09` in `Europe/London`.
