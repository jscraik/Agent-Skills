Required:
1. The TOML file itself, or the absolute path to it.
2. The intended scope:
   - `validation-only`
   - `global`
   - `project`
   - `repo-owned`
3. The canonical source path, if the TOML is not the source of truth.
4. An evidence source:
   - local schema evidence
   - official docs
   - existing validator output
   - runtime/config-load evidence

Strongly recommended for a clean validation:
1. The target agent name exactly as it should be loaded.
2. The validation goal:
   - `syntax only`
   - `schema / field contract`
   - `discoverability`
   - `runtime posture`
   - `full role validation`
3. The declaring config path, if the role is wired through `[agents.<name>]` or another config layer.
4. Any config-layer context that affects discovery:
   - `config.toml`
   - `.codex/agents/*.toml`
   - project or repo-owned discoverability wiring
