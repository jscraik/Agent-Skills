# ChatGPT Icon + Logo Prompt Pack (Category-Directed)

Use this file to generate all skill and plugin visuals in ChatGPT with stricter art direction.

## Core Family Rules
- Rounded-corner geometric silhouette with medium stroke weight.
- No text, no letters, no numbers, no watermark.
- Transparent background, centered mark, balanced negative space.
- Readable at tiny sizes; avoid thin detail and visual noise.

## Style Profiles

### Security
- Palette: Deep slate + ember amber + danger red accents
- Motif: Shield, lock, boundary, alert geometry
- Texture: Subtle hard-edge facets, high-contrast edges
- Mood: Trustworthy, defensive, precise

### Frontend
- Palette: Cobalt + cyan + electric mint accents
- Motif: Layout grids, viewport frames, component blocks, motion arcs
- Texture: Softer gradients with crisp shape boundaries
- Mood: Creative, modern, interactive

### Ops
- Palette: Teal + green + graphite neutrals
- Motif: Pipelines, nodes, automation loops, reliability checkpoints
- Texture: Flat-to-subtle depth, clean technical geometry
- Mood: Operational, stable, execution-focused

### Docs
- Palette: Indigo + slate + cool gray accents
- Motif: Pages, layers, maps, knowledge cards
- Texture: Clean planes and tidy spacing cues
- Mood: Structured, legible, reference-oriented
