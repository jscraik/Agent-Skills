Suggestions

  • Add more natural trigger terms or synonyms users might say, such as 'agent configuration', 'TOML config files', 'custom roles', or 'subagent setup'.
  • Clarify domain-specific terms like 'fold' and 'agent discoverability config' so the description is self-explanatory without prior context.
  • Add a concrete, copy-paste-ready TOML role file example at the top (Quick Start) showing a minimal valid agent role with required fields like developer_instructions, name, and description.
