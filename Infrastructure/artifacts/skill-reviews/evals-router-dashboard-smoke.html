Review Lanes

How this local dashboard separates behavior checks, static guardrails, Tessl review, and optional security screening.

Local Evals

dynamic run-trace behavior checks for skill selection, commands, artifacts, and release gates

./bin/ask evals run <path> --mode smoke|release --json --robot

Plugin Eval

static budget, ergonomics, and reviewability guardrail; not a substitute for local evals

plugin-eval analyze <path> --format markdown

Tessl Lint

disposable tile.json package-shape check, not a direct content finding

canonical source shape: SKILL.md-first
tessl skill lint <temporary-tile.json>

Tessl Review

local best-practice/content review for private or work-in-progress skills

tessl skill review <temporary-skill-directory>
