# OpenAI Cookbook Skill Opportunities

This is an intake note for future skill work. Use
openai-cookbook-skill-expertise-map.md for routing and
openai-cookbook-expert-lens-pack.md for reusable checks.

## High-Leverage Opportunities

- Strengthen evals-router with failure taxonomies, baselines, labeled examples,
  judge calibration, regression checks, and artifact-specific eval modes.
- Strengthen skill-builder with a reproduce-patch-eval-rerun loop for skill
  defects and budget regressions.
- Strengthen mcp-builder and backend-engineer with tool orchestration,
  structured output, auth, and schema verification checks.
- Strengthen keep-codex-fast and project-brain with memory compaction,
  provenance, freshness, and stale-evidence checks.
- Strengthen pr-green-sweep, autofix, and codex-review with secure quality-gate
  ownership and live blocker classification.

## Do Not Do

- Do not paste Cookbook notebook code or prompt text into skill packages.
- Do not create a new skill before checking existing ownership.
- Do not replace repo validation with Cookbook authority.
