# Skills SDK Brand Agent Guide

## Scope

- Applies to `skills-sdk/brand/**`.
- Inherits the repository root [AGENTS.md](../../AGENTS.md).

## Edit Policy

- Treat brand files as user-facing product assets. Preserve original asset
  formats, filenames, dimensions, and transparent backgrounds unless the task
  explicitly asks for an asset change.
- Do not invent product claims, positioning, or usage rights. Keep brand copy
  source-backed and aligned with nearby README or product docs.
- When replacing binary assets, keep the source, export format, and visual check
  evidence clear in the closeout.

## Context Pointers

- Brand entrypoint: [README.md](README.md).
- Repository vocabulary: [UBIQUITOUS_LANGUAGE.md](../../UBIQUITOUS_LANGUAGE.md).

## Validation

- For copy-only changes, validate links and surrounding Markdown.
- For image changes, inspect the rendered asset and report the exact file paths
  changed; do not claim app/runtime proof unless the asset was viewed in its
  consuming surface.
