# TruffleHog

## Configuration

TruffleHog requires a config file in the repository. CodeRabbit supports:

- `trufflehog-config.yml`
- `trufflehog-config.yaml`
- `trufflehog.yml`
- `trufflehog.yaml`
- `.trufflehog.yml`
- `.trufflehog.yaml`

If none of these files exists, CodeRabbit skips TruffleHog.
