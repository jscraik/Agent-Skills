# Management Overview

Manage your CodeRabbit platform: subscriptions, teams, integrations, and analytics.

The Management section provides administrative tools to configure, monitor, and optimize your CodeRabbit deployment.

## Dashboard & Metrics

Track team performance, review velocity, and code quality metrics

## Reports

Generate scheduled or on-demand reports about pull request activity

## Repository Setup

Connect CodeRabbit with GitHub, GitLab, Azure DevOps, or Bitbucket

## Account Management

Manage subscriptions, seats, roles, and billing

## Dashboard and Reports

Monitor team performance with the CodeRabbit Dashboard, tracking review velocity, code quality, and collaboration patterns. Generate custom reports on-demand or schedule automated delivery via email, Slack, Discord, or Microsoft Teams.

## Repository Configuration

Connect repositories from supported Git platforms including GitHub, GitLab, Azure DevOps, and Bitbucket. Configure CodeRabbit behavior using organization settings, repository settings, or YAML configuration files.

## Account Management

Manage your subscription and billing, adjust team seats, and control access through role-based permissions (Admin, Member, Billing Admin). Add organizations and upgrade permissions as needed.

## What's next

- Set up repositories — Connect your Git platform to start reviewing code
- Monitor performance — Track team metrics and measure impact
- Manage your team — Set up roles and manage permissions
- API access — Access data programmatically for custom integrations
