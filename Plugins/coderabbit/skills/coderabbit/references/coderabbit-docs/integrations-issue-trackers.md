# Issue Trackers

CodeRabbit integrates with popular issue tracking systems to enrich reviews with issue context, validate requirements, create issues from review comments, and design Coding Plans.

This feature is available exclusively as part of the Pro plan.

## Supported integrations

- **GitHub Issues** - Works automatically without setup
- **GitLab Issues** - Works automatically without setup
- **Jira** - Connect via the CodeRabbit Forge app from Atlassian Marketplace
- **Linear** - OAuth-based integration for Linear workspaces

## Features

CodeRabbit connects with your issue tracking systems to bring issue context into every stage of development, from planning through code review.

- **Context enrichment** - Pulls in issue details: descriptions, acceptance criteria, and discussions, so CodeRabbit understands why a change is being made.
- **Requirement validation** - Assesses whether your code changes properly address the linked issue's acceptance criteria and flags any gaps.
- **Issue planning** - Analyzes your issues and codebase to generate step-by-step Coding Plans for a handoff to any coding agent or IDE copilot.
- **Issue creation** - Creates new issues directly from PR review comments, ensuring nothing discussed during review gets lost.

- **Jira** - Install and configure the Jira Cloud integration via the Atlassian Marketplace
- **Linear** - Install and configure the Linear integration via OAuth
