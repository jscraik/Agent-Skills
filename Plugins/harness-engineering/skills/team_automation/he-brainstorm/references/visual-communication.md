# Visual Communication

Load full doctrine when needed: `Infrastructure/references/harness-engineering/he-brainstorm-doctrine.md`.

Use visuals only when they improve comprehension:
- Workflow: Mermaid or ASCII flow.
- Three or more modes, states, roles, systems, or variants: table or relationship diagram.
- Competing approaches: comparison table.

Skip visuals that restate prose or drift into implementation architecture, schemas, or code structure for `he-plan`. Prose governs if a visual disagrees.
