# AI Native DevCon 2026 London

This local Codex plugin wraps the Tessl tile
`ainativedev/aidevcon-2026-ldn@0.100.8`. It contains one skill for each AI
Native DevCon 2026 London session, with the talk transcript, outline, and
selected quotes bundled beside the skill.

## What's Inside

Each talk skill covers:

- the core ideas, frameworks, and patterns introduced in the session;
- practical techniques and implementation guidance from the speaker;
- key takeaways grounded in the bundled transcript.

Every talk skill includes:

| File | Purpose |
| --- | --- |
| `SKILL.md` | Skill definition and grounding rules |
| `transcript.md` | Full transcript |
| `outline.md` | Section map for navigation |
| `quote.md` | Pre-extracted supporting quotes by theme |

## Usage

Ask questions across the conference talks:

- "What did Ryan Lopopolo cover in his session on harness engineering?"
- "Which talks discussed context engineering?"
- "Compare the testing themes in the observability and benchmarking talks."
