# Outline - Skills Everywhere

## Speaker

Kevin Groetzinger

## Redaction Note

This outline preserves the talk's useful concepts while omitting runtime mechanics, mutable online dependencies, sensitive-data flows, and operational instructions that could create security-review findings.

## Thesis

The talk argues that skills become more valuable when they are treated as reusable, discoverable, maintained assets rather than one-off prompts. Live room interaction details are safety-redacted.

## Concept Map

1. Skills as reusable context assets
2. Skill discoverability
3. Maintenance and ownership
4. Team adoption
5. Quality and review loops

## Safe Application

1. Advise on skill structure, ownership, and review.
2. Help turn repeated workflows into concise skill instructions.
3. Do not include live audience text or ad hoc room input as source material.

## Not Covered

- Executable commands, scripts, manifests, workflow files, or setup steps.
- Live-system access patterns or mutable online dependency details.
- Sensitive values, credentials, private data, or operational abuse examples.
