# Outline -- Harness Engineering: How to Build Software When Humans Steer and Agents Execute

**Speaker:** Ryan Lopopolo (OpenAI)

## Thesis

Ryan Lopopolo explains harness engineering as the discipline of making agent work safe, repeatable, and useful by shaping autonomy, context, tool access, feedback loops, and verification.

## Concept Map

1. Harness engineering
2. Human steering and agent execution
3. Context shaping

5. Verification and eval loops
6. Feedback systems for agent work
