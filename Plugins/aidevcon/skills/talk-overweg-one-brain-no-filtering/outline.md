# Outline - One Brain, No Filtering

## Speaker

Robert Overweg

## Redaction Note

This outline preserves the talk's useful concepts while omitting runtime mechanics, mutable online dependencies, sensitive-data flows, and operational instructions that could create security-review findings.

## Thesis

The talk explores a unified knowledge-memory pattern for AI work: keep useful context available, make retrieval explicit, and preserve provenance. Runtime loading mechanics are safety-redacted.

## Concept Map

1. Unified knowledge memory
2. Context retrieval
3. Provenance and trust
4. Personal/team knowledge workflows
5. Reducing premature filtering

## Safe Application

1. Design a local, curated knowledge layout.
2. Recommend provenance labels and review checkpoints.
3. Do not depend on mutable online sources.

## Not Covered

- Executable commands, scripts, manifests, workflow files, or setup steps.
- Live-system access patterns or mutable online dependency details.
- Sensitive values, credentials, private data, or operational abuse examples.
