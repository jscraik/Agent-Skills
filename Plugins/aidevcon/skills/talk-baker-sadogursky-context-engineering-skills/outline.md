# Outline -- Don't Write Prompts, Write Software

**Speakers:** Macey Baker and Baruch Sadogursky (Tessl)

## Thesis

Macey Baker and Baruch Sadogursky frame reusable agent behavior as software: rules for always-on constraints, skills for reusable judgment, scripts for deterministic work, hooks for integration points, and evals for confidence.

## Concept Map

1. Rules versus skills
2. Scripts for deterministic work
3. Skills for reusable judgment
4. Hooks and integration points
5. Evals for reusable context
6. Context as maintained software
