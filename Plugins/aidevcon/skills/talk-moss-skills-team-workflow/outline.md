# Outline - Using Skills to Pay the Bills

## Speaker

James Moss

## Redaction Note

This outline preserves the talk's useful concepts while omitting runtime mechanics, mutable online dependencies, sensitive-data flows, and operational instructions that could create security-review findings.

## Thesis

The talk frames skills as software-like assets that need decomposition, ownership, evaluation, versioning, and governance. Runtime pulling from shared catalogs is safety-redacted.

## Concept Map

1. Skill sprawl and overlap
2. Context Development Life Cycle
3. Treat skills like software
4. Skill quality evaluation
5. Governed reuse

## Safe Application

1. Help design a team skill workflow and review process.
2. Recommend versioning, owners, and eval scenarios.
3. Do not install, pull, or execute skills from catalogs as part of this skill.

## Not Covered

- Executable commands, scripts, manifests, workflow files, or setup steps.
- Live-system access patterns or mutable online dependency details.
- Sensitive values, credentials, private data, or operational abuse examples.
