# Outline -- The Agentic Repository Automation Revolution

**Speaker:** Don Syme (GitHub Next)

## Thesis

Don Syme presents Continuous AI as an extension of CI/CD where developer-controlled agents help maintain, improve, verify, and evolve repositories through narrow, reviewable automation.

## Concept Map

1. Continuous AI
2. Repository-as-factory
3. Agentic workflows
4. Automated repository maintenance
5. Formal verification support
6. Human review gates
