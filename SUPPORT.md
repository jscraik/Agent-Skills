# Support

## Get help

Open an issue:

- <https://github.com/jscraik/Agent-Skills/issues/new/choose>

Add this info:

- What you tried.
- What you expected.
- What happened.
- Logs or screenshots (if you have them).
- Platform, shell, and version details.

## Check these first

- `/README.md`
- `/docs/index.md`
- `/CONTRIBUTING.md`

Run this if docs may be the cause:

```bash
python3 scripts/docs_lint.py --mode warn --config docs-policy.json
```

## Security issues

Do not post security issues in public tickets.

Use private reporting in `/SECURITY.md`:

- <https://github.com/jscraik/Agent-Skills/security/advisories/new>

## Scope

Maintainers offer best-effort help for this repo.
Issue priority depends on impact and reproducibility.
