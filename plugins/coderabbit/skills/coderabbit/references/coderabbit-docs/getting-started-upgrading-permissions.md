# Upgrading Permissions

When CodeRabbit ships new features, additional GitHub permissions may be required. If you see permission warnings or missing functionality, follow this guide.

## When you need to update permissions

You likely need updated permissions if:

- CodeRabbit displays a permission warning
- Features that previously worked are now unavailable

![Permission warning example](https://mintcdn.com/coderabbit/D_rqUjBaYiE185JH/images/getting-started/assets/images/permission-warning-5ae71501a21d040a0a3142c6ae247393.png?fit=max&auto=format&n=D_rqUjBaYiE185JH&q=85&s=5e620abe3a46fb8e9c312b5f10515087)

## Update permissions

1. Open your GitHub organization or repository settings.
2. Go to **GitHub Apps** (or **Installed GitHub Apps**).
3. Find **CodeRabbit** in the installed apps list.
4. Click **Configure**.
5. Review requested permissions and click **Accept new permissions**.

## Why permissions are updated

CodeRabbit may request new permissions for:

- New GitHub API features
- Enhanced repository analysis
- Workflow automation improvements
- Security capability upgrades

If you are not an org admin, ask an admin to approve the permission upgrade.

## Troubleshooting

If issues continue after approval:

1. Refresh browser and clear cache.
2. Wait a few minutes for propagation across GitHub systems.
3. Contact [support](/support) if problems persist.
