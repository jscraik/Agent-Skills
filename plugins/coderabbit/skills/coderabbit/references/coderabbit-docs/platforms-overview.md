# Overview

Connect CodeRabbit with your preferred Git platform including GitHub, GitLab, Azure DevOps, and Bitbucket for AI-powered code reviews right in your PR.

CodeRabbit seamlessly integrates with all major Git platforms to bring AI-powered code reviews directly to your development workflow. Choose your platform below to get started with step-by-step integration guides.

## Supported Git platforms

- **GitHub.com** -- Connect your GitHub.com repositories for instant AI code reviews
- **GitHub Enterprise Server** -- Self-hosted GitHub integration for enterprise teams
- **GitLab.com** -- Integrate with GitLab.com for comprehensive code analysis
- **Self-managed GitLab** -- Connect your on-premises GitLab instance
- **Azure DevOps** -- Seamless integration with Microsoft Azure DevOps
- **Bitbucket Cloud** -- AI code reviews for your Bitbucket Cloud repositories

**Need enterprise-grade deployment?** CodeRabbit offers a self-hosted option for Enterprise customers with 500+ user seats. Contact our sales team to learn more about CodeRabbit Enterprise.

## Integration process

While each Git platform has specific setup requirements, the general integration process follows these steps:

1. **Authenticate with your Git platform** -- Log into CodeRabbit using your Git platform account credentials for secure, streamlined access.

2. **Add your organizations** -- Connect the organizations containing repositories you want CodeRabbit to review. You'll need ownership-level permissions for these organizations.

   Different platforms use different terminology: "organizations" on GitHub, "groups" on GitLab, and "workspaces" on Bitbucket.

3. **Configure service account** -- Create a dedicated CodeRabbit service account if required. Some platforms like GitHub.com handle this automatically.

4. **Grant repository permissions** -- Authorize CodeRabbit to access the specific repositories where you want AI code reviews enabled.

Once integration is complete, CodeRabbit immediately begins reviewing pull requests with its default configuration. You can then customize the configuration to match your team's specific needs and coding standards.
