# TruffleHog

## Configuration
TruffleHog **requires** a config file in the repository. CodeRabbit allows the following to be used:

- `trufflehog-config.yml`

- `trufflehog-config.yaml`

- `trufflehog.yml`

- `trufflehog.yaml`

- `.trufflehog.yml`

- `.trufflehog.yaml`

If none of these are found, TruffleHog is skipped for the run.
