## Noticing
- Treat first reaction as shallow data, not conclusion.
- Stay with the artifact longer and log concrete observations.
- Build taste by tracking reactions and identifying causes.

## Conceptual Range
- Avoid early commitment to the first obvious idea.
- Generate structurally different options, not cosmetic variants.
- Expand via inversion, modality shifts, and constraint changes.

## Conceptual Depth
- Once a direction is chosen, iterate beyond baseline polish.
- Use a level spectrum (e.g., 1→10) to push quality intentionally.
- Depth is often where distinctiveness appears.
- Layer surface, interaction, and sensory detail deliberately.

## Live Tuning
- Expose key parameters for real-time adjustment.
- Feel differences instantly to accelerate intuition.
- Use parametric controls to discover combinations you would not guess.

## Uncommon Care
- Quality is visible in edge cases, errors, and overlooked details.
- Go beyond expected scope where it improves trust and delight.
- Use extra leverage/time to add meaningful human touches.
- Small details (hints, reset behavior, tactile audio variation) can create memorable moments.

## Separation of Concerns
- Resolve one question at a time with fit-for-purpose fidelity.
- Build minimal prototypes for confidence before full production depth.
- Intentional sequencing beats all-at-once complexity.

## Facets of Quality
- Define 3–5 project-specific quality facets.
- Score and track over time to steer roadmap and critique.
- Use facets as shared language for team decisions.

## Less, but Better
- Reduce non-essential scope and interactions.
- Prefer fewer elements executed exceptionally well.
- Repeatedly remove, simplify, and refine.

## Recreate Everything
- Rebuild inspiring interactions quickly to learn by doing.
- Use minimal playgrounds and focus on one technical question.
- Stop when learning objective is reached, then document reusable pattern.

## Industry Standards
- Users benchmark implicitly against apps they use daily.
- Falling below baseline can undermine trust immediately.
- Start from platform/category defaults, then improve intentionally.

## Refinement Case Pattern
- Run critique, apply targeted refinements, then critique again.
- Typical refinements: icon consistency, alignment simplification, noise reduction, hierarchy clarity.
- Small changes can compound into major quality gains when they align the whole visual language.

## Tools Match the Medium
- Prefer adaptive/responsive primitives over fixed-canvas assumptions.
- Choose workflows that preserve real interaction constraints.

## Real Data + Systems
- Design with realistic content and edge cases early.
- Build with reusable components and constraints, not ad-hoc screens.
