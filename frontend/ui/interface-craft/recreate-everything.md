# Recreate Everything

Reverse-engineer inspiring interactions by rebuilding them quickly in a focused playground.

---

## When to Use

Use when users ask:
- “How did they do this interaction?”
- “Can we recreate this effect?”
- “I want to learn this pattern by rebuilding it.”

Best for skill building and technique discovery, not production-hardening.

## Core Mindset

No shortcuts to learning: build it, fail, iterate, learn.

Target a **single learning objective** per recreation attempt.
Do not over-polish if the objective is already met.

## Workflow

1. **Capture inspiration**
   - Describe what behavior is interesting and why.

2. **Define the learning objective**
   - One question only (e.g., deformation behavior, spring feel, curve profile).

3. **Build a breakable playground**
   - minimal UI shell
   - only essentials for observing the effect

4. **Iterate in short loops**
   - start simple
   - add one complexity layer at a time
   - evaluate against the source feel

5. **Stop at sufficient understanding**
   - document what worked
   - record limitations and next experiments

6. **Add to toolbelt**
   - summarize reusable technique/pattern

## Output Format

```md
## Inspiration Target
[what effect is being recreated]

## Learning Objective
[single question]

## Minimal Playground Plan
[smallest implementation to test objective]

## Iteration Notes
[what changed, what improved]

## Reached Outcome
[what was learned + confidence level]

## Reusable Pattern
[how to apply elsewhere]
```
