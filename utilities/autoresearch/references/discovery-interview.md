# Discovery Interview Templates

Read when: required loop controls are missing (stop condition, success goal, target scope), or when ambiguity would make keep/discard decisions unsafe.

## Request user input mini-templates

- Round 1:
  - Question: `What should this skill help you do?`
  - Why this matters: it sets the concrete job-to-be-done so iteration scoring stays meaningful.
- Round 2:
  - Question: `Which target paths should we include first?`
  - Why this matters: scope boundaries prevent drift into unrelated product code.
- Round 3:
  - Question: `What stop condition should end this run (timebox or iteration cap)?`
  - Why this matters: bounded runs preserve operator control and auditability.
- Round 4:
  - Question: `What success goal should count as a win?`
  - Why this matters: explicit goals keep/discard decisions objective.
