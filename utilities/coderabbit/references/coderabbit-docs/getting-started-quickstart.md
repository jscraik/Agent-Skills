# Quickstart

Get CodeRabbit up and running in 2 minutes. Connect your repositories and start receiving AI-powered code reviews and Coding Plans.

Want a guided tour? Explore key features with our hands-on guide using a provided demo project.

## Initial Setup

1. Sign up with your Git platform
   Use your existing GitHub, GitLab, Azure DevOps, or Bitbucket account to create your CodeRabbit account. No credit card required!

2. Add your repositories
   Add repositories that CodeRabbit should review. You control exactly which repos have access. For detailed instructions, choose your Git platform below.

   - GitHub.com - Public or private GitHub repositories
   - GitHub Enterprise Server - GitHub integration for enterprise teams
   - GitLab.com - Integrate with cloud GitLab.com
   - Self-managed GitLab - Connect your self-hosted GitLab instance
   - Azure DevOps - Seamless integration with Microsoft Azure DevOps
   - Bitbucket Cloud - AI code reviews for your Bitbucket Cloud repositories

## What's Next

You're all set! Here's what you can do now:

- Pull Request Reviews - Open a pull request and get actionable AI feedback within minutes.
- IDE & CLI Reviews - Review uncommitted changes in VS Code, Cursor, Windsurf, or from the command line.
- Coding Plans - Comment `@coderabbitai plan` on any issue to generate a detailed coding plan grounded in your codebase.

CodeRabbit provides highly valuable feedback right from the start, but you can get even more by explaining your team standards, code style agreements and project specifics. Explore language-specific examples and hands-on guide to make yourself familiar with most important features and settings.
