# Plain-Language Glossary (Interview Kernel)

Use this glossary for **inline translations** in questions and synthesis.
Rule: if a term appears **2+ times** in an interview and isn’t listed here, add it.

## Terms (inline translations)

- **SLO** — uptime/latency target (“how reliable it should be”)
- **SLA** — contractual reliability promise
- **Latency** — how long a response takes
- **Throughput** — how much work is processed per unit time
- **P95/P99** — “slowest 5% / 1% of requests”
- **Rollback** — revert to the previous version
- **Feature flag** — switch to enable/disable a feature safely
- **Regression** — a bug introduced by a change
- **Migration** — moving data or behavior to a new structure
- **Schema** — the shape of stored data
- **Idempotent** — safe to run multiple times with the same result
- **Rate limit** — cap on request frequency
- **Throttling** — slowing requests under load
- **Backfill** — fill missing historical data
- **Cold start** — slower first run after idle
- **Hot path** — code executed most often
- **Observability** — logs/metrics/traces to see what’s happening
- **Telemetry** — data about system behavior
- **Incident** — outage or serious degradation
- **Mitigation** — immediate step to reduce harm
- **Blast radius** — how much is affected when things fail
- **Canary** — small rollout to reduce risk
- **Staged rollout** — gradual release
- **Big-bang release** — release to everyone at once
- **Degraded mode** — reduced features to stay available
- **Invariant** — condition that must always be true
- **Edge case** — rare input that can break assumptions
