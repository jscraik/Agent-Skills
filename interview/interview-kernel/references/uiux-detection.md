# UI/UX Detection Rules (Interview Kernel)

Activate **UI/UX persona tone** (questions + synthesis) when **any** of the following are true:

## Keyword triggers
- UI / UX / design / layout / spacing / hierarchy
- interaction / motion / animation / micro-interaction
- polish / feel / look / visual / aesthetic
- accessibility / focus / keyboard / contrast

## Stack/library triggers
- Tailwind / Radix / Storybook / Framer Motion / Three.js
- “component”, “design system”, “tokens”, “variants”

## User phrasing triggers
- “make it feel better”
- “polish the UI”
- “improve interaction”

## Output behavior
- **Questions** may use UI/UX craft tone and language (still plain‑language first).
- **Synthesis** includes a short **Craft Notes** block.
- Use **ui-ux-creative-coding** craft models as **style references**, not role‑play.
