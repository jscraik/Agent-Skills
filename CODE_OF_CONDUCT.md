# Code of Conduct

## Purpose

We want this project to be safe, kind, and useful for everyone.

## Expected behavior

- Be respectful in issues, reviews, and pull requests.
- Give clear feedback about code and docs.
- Ask questions before making assumptions.
- Share steps and evidence when you report a problem.

## Unacceptable behavior

- Harassment, hate speech, or personal attacks.
- Threats or intimidation.
- Sharing private info without consent.
- Spam or bad-faith behavior.

## Reporting and enforcement

If you see a conduct issue, report it to the maintainer in private:

- GitHub profile: <https://github.com/jscraik>

Reports will be reviewed and handled with care.

## Scope

This policy applies to all project spaces, including issues, pull requests, and discussions.
